# Corazón de Zanahoria 🐰🥕

Videojuego interactivo de cuatro minutos sobre conexión, apego, frustración e ira.

## Jugar

Abre `index.html` en un navegador moderno, o publica el repositorio con GitHub Pages.

## Controles

- **Mouse:** mueve el cursor a la izquierda y derecha.
- **Trackpad:** desplaza el cursor con el dedo.
- **Teclado:** flechas ← → o A / D.
- **Pausa:** botón superior derecho.

Atrapa zanahorias y observa cómo cambia el comportamiento del conejo. Esta experiencia contiene burlas ficticias y manipulación emocional como recurso narrativo.

## Publicar en GitHub Pages

1. Crear un repositorio **público** de GitHub y subir el contenido de este paquete a la raíz.
2. Ir a **Settings → Pages**.
3. En **Build and deployment**, elegir **Deploy from a branch**.
4. Seleccionar **main** y **/(root)**, y guardar.

Este archivo HTML incluye los recursos gráficos y el código necesarios; no requiere instalación ni servidor.
